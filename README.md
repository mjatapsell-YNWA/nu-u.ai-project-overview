# nu-u.ai-project-overview # Nu-U.ai — AI-Powered Health Support Platform

## Overview

Nu-U.ai is a digital health support platform designed to help people maintain weight loss after completing GLP-1 medication treatment. It combines an AI chatbot, tailored user journeys and peer support to help users access relevant information and ongoing lifestyle support.

I founded and led the development of Nu-U.ai through Rtn2 App Ltd, coordinating product requirements, external developers, testing and deployment.

## The Problem

People completing GLP-1 treatment may need continuing support to maintain their weight loss. Nu-U.ai was designed to provide accessible, ongoing support through a digital platform combining AI-generated conversations with relevant health information.

## How the Platform Works

The platform uses a large language model (LLM) alongside retrieval-augmented generation (RAG).

- **User interaction:** The chatbot uses tailored prompts and questions to guide conversations.
- **Knowledge retrieval:** RAG retrieves relevant information from a curated collection of documents, including NHS and NICE guidance.
- **AI response generation:** Retrieved information provides context for the language model's responses.
- **Supporting functionality:** The wider platform includes user access, payment integration and peer support features.

## Technology

- OpenAI APIs for language-model functionality
- Pinecone vector database for information retrieval
- Retrieval-augmented generation (RAG)
- Stripe payment integration
- Python and FastAPI experimentation for a separate working RAG implementation

## My Role

As founder and project manager, I translated the business concept into product requirements and coordinated external developers through development, testing and deployment.

I worked with developers on AI integrations and retrieval workflows, considered data protection and security requirements, and used AI coding assistants to generate and adapt Python code for a working RAG environment.

My role combines product ownership, technical coordination, user requirements and practical problem-solving rather than professional software engineering.

## Key Learning

The project reinforced the importance of connecting AI capabilities to a real user need, structuring information for retrieval, designing useful user journeys and considering security and responsible use when developing a health-related digital service.

Nu-U.ai is a support platform, not a medical device, and is not presented as providing clinical decision support.
